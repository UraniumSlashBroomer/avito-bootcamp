# Определение поворота текста на 180°

Решение задачи бинарной классификации ориентации текстовых кропов: модель оценивает вероятность того, что изображение перевёрнуто на 180°. Основной эксперимент, обучение, валидация и анализ ошибок собраны в [`main.ipynb`](./main.ipynb).

В качестве классификатора используется `MobileNetV3-Small` с одним выходным логитом. Изображения приводятся к размеру `160×320` с сохранением соотношения сторон и дополнением фона медианным цветом границы. Результат инференса — значение `p_180` в диапазоне `[0, 1]`; качество вероятностных предсказаний оценивается в том числе по Brier score.

## Описание репозитория

Основные файлы:

```text
.
├── main.ipynb
├── mobilenet_rotation_easy_aspect_160x320_best.pt
├── requirements.txt
└── submission.csv
```

- `main.ipynb` — полный экспериментальный пайплайн: подготовка split, обучение или загрузка checkpoint, расчёт метрик, анализ ошибок и генерация submission;
- `mobilenet_rotation_easy_aspect_160x320_best.pt` — лучший checkpoint модели для входа `160×320`;
- `requirements.txt` — зафиксированные версии зависимостей;
- `submission.csv` — подготовленные предсказания в формате `image_id,p_180`.

Train/validation разделяются по `from_image_id`, поэтому кропы, полученные из одной исходной фотографии, не попадают одновременно в обе части выборки. Валидация содержит обе ориентации каждого кропа: `0°` и `180°`.

Ноутбук поддерживает два режима:

1. Полный запуск — обучение, валидация, анализ и инференс. Для него нужен полный датасет.
2. Только инференс — последние две ячейки используют checkpoint и тестовые изображения, не загружая train-датасет.

## Установка и запуск

Рекомендуемая версия Python — `3.14` (исходное окружение создано на Python `3.14.4`).
Обучал на GPU, получить submission можно на CPU, займет пару минут.

Создайте и активируйте виртуальное окружение:

```bash
python -m venv .venv

если на Linux:
source .venv/bin/activate

или если на Windows:
cd scripts/activate
activate.bat
cd ../../
```


Установите зависимости и запустите jupyter lab из корня репозитория:

```bash
pip install -r requirements.txt
jupyter lab
```

Пути в ноутбуке строятся относительно текущей рабочей директории, поэтому Jupyter необходимо запускать именно из корня проекта.

### Полное воспроизведение ноутбука

Скачайте и распакуйте датасет по инструкции ниже. После распаковки ожидается следующая структура:

```text
data_merged_easy/
├── manifest.csv
└── images/
    └── ...
```

Затем откройте `main.ipynb` и выполните ячейки сверху вниз. Ключевые параметры находятся в первой кодовой ячейке:

- `FORCE_TRAIN = False` — загрузить существующий checkpoint и пропустить обучение;
- `FORCE_TRAIN = True` — обучить модель заново;
- `RUN_EXPERIMENTS = ('aspect_160x320',)` — запустить основной вариант;
- `RUN_EXPERIMENTS = ('square_224', 'aspect_160x320')` — дополнительно воспроизвести сравнение способов подготовки входа.

Лучший checkpoint выбирается по минимальному validation Brier score.

### Только генерация submission

Для автономного инференса достаточно:

```text
main.ipynb
mobilenet_rotation_easy_aspect_160x320_best.pt
test/images/*
```

В новом kernel выполните последние две кодовые ячейки раздела **«Submission для модели 160×320»**. Они самостоятельно создают модель, загружают checkpoint, обрабатывают изображения из `test/images` и записывают результат в `submission.csv`:

```text
image_id,p_180
example_001,0.0137
example_002,0.9842
```

`p_180` — вероятность поворота на 180°
